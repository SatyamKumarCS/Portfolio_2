Welcome to my personal 3D portfolio! This project is a showcase of my journey as a **Full Stack & AI/ML Developer**, blending immersive 3D experiences with high-performance web applications and intelligent agentic systems.

---

## ✨ Key Features

- **🌀 Immersive 3D Experience**: Integrated **React Three Fiber** and **Drei** for dynamic 3D elements, including custom shaders and interactive models.
- **🤖 Agentic AI Ready**: Built with **LangChain** and **LangGraph** integrations, demonstrating production-grade AI underwriting and content generation workflows.
- **⚡ Peak Performance**: Built on **Vite** and **React 19** for blazing-fast load times and optimal bundle sizes.
- **🎨 Modern Aesthetics**: Styled with **Tailwind CSS 4**, featuring glassmorphism, fluid animations via **GSAP** and **Framer Motion**, and smooth scroll reveals with **AOS**.
- **💬 Real-time Interactions**: Feature-rich **Chat Room** powered by **Firebase** for seamless user engagement.

## 📦 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/SatyamKumarCS/portofolio.git
   cd portofolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up Environment Variables**
   Create a `.env` file and add your Firebase credentials:
   ```env
   VITE_FIREBASE_API_KEY=your_key
   VITE_FIREBASE_AUTH_DOMAIN=your_domain
   ...
   ```

4. **Run development server**
   ```bash
   npm run dev
   ```

5. **Build for production**
   ```bash
   npm run build
   ```
